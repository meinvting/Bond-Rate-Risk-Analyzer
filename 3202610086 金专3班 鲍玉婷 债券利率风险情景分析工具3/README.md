# 债券利率风险情景分析工具（Bond Interest Rate Risk Scenario Analyzer）

> 《金融市场与金融机构》课程期中持续项目 · 3202610086 金融专硕 3 班 鲍玉婷 

## 项目简介

在利率频繁波动的市场中，普通投资者与初学金融的学生往往只知道"利率涨、债券价格跌"的结论，却难以直观理解**期限**与**票面利率**如何决定一只债券对利率变化的敏感程度。

本项目基于课程第十二章"债券市场"，构建一个**可复现的 Excel 利率风险情景分析工具**：用户输入债券基本要素与市场利率情景，即可自动得到债券理论价格、当期收益率、不同利率冲击下的价格涨跌幅，并通过敏感性图表与多期限对比表，直观验证"期限越长、票面利率越低，利率风险通常越大"这一核心结论。期末计划升级为可交互网页。

## 核心功能

- **债券定价**：基于 `PV` 函数实现半年付息债券的现金流折现，支持面值、票面利率、期限、付息频率、市场利率灵活输入。
- **教材例题校验**：准确复现教材例题 12-3（面值 1,000 美元、票息 10%、2 年、半年付息、市场利率 12% → **965.35 美元**），作为模型正确性的"黄金校验"。
- **利率情景分析**：一键计算 −1% ~ +1% 多档利率冲击下的新价格与涨跌幅。
- **期限敏感性对比**：对比 2 / 5 / 10 年期债券在同一利率冲击下的价格反应，验证"期限越长、跌幅越大"。
- **可视化**：自带动态敏感性折线图与期限对比柱状图。

## 使用说明

1. 用 Microsoft Excel 打开 `债券利率风险分析器2.xlsx`；
2. 在"输入区"填写债券基本要素（面值、票面利率、期限、付息次数、市场利率）；
3. 在"利率情景"区选择或填写利率变动幅度，工作簿自动计算新价格与涨跌幅；
4. 查看"利率情景分析表""期限敏感性对比表"与动态图表，验证利率风险结论；
5. **校验**：查看 **B12「教材例题12-3校验」** 单元格，应自动显示 **"验证通过"**（基于 B9 理论价格四舍五入 2 位 = 965.35 美元判定；若参数被改动导致偏离则显示"验证失败"）。
